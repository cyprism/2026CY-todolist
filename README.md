# 2026 초록 플래너

2026년의 일정과 할 일을 일간·주간·월간 단위로 관리할 수 있는 달력형 투두리스트 웹 서비스입니다.

초록색을 중심으로 편안하고 산뜻한 화면을 구성했으며, 배경의 나뭇잎 이모지가 천천히 떠다니도록 표현했습니다. 별도의 회원가입이나 설치 없이 브라우저에서 바로 사용할 수 있습니다.

## 서비스 바로가기

[2026 초록 플래너 열기](https://green-planner-2026.rinaaaab.chatgpt.site)

> 현재 비공개 사이트로 게시되어 있어 접속 시 로그인이 필요할 수 있습니다.

## 주요 기능

- 2026년 전체 달력 탐색
- 날짜별 할 일 추가 및 삭제
- 체크박스를 이용한 완료 상태 관리
- 일간, 주간, 월간 보기 전환
- 높음, 보통, 낮음의 3단계 중요도 설정
- 중요도에 따른 초록 계열 색상 구분
- 날짜별 할 일 개수와 완료 현황 표시
- 2026년 연간 진행률 표시
- 브라우저 로컬 저장소를 이용한 데이터 자동 저장
- 데스크톱과 모바일을 지원하는 반응형 화면
- 움직임 감소 설정을 고려한 애니메이션 처리

## 중요도 색상

| 중요도 | 의미 | 표시 방식 |
| --- | --- | --- |
| 높음 | 꼭 처리해야 하는 일 | 진한 초록색 |
| 보통 | 일반적인 일정과 할 일 | 중간 초록색 |
| 낮음 | 여유가 있을 때 처리할 일 | 회색빛 초록색 |

## 사용 방법

1. 왼쪽 달력에서 할 일을 기록할 날짜를 선택합니다.
2. 입력창에 새로운 할 일을 작성합니다.
3. 중요도를 선택한 후 `추가` 버튼을 누릅니다.
4. 완료한 항목은 체크박스를 눌러 완료 상태로 변경합니다.
5. 상단의 `일간`, `주간`, `월간` 탭으로 기간별 계획을 확인합니다.
6. 필요 없는 항목은 오른쪽의 `×` 버튼으로 삭제합니다.

## 데이터 저장 방식

할 일은 브라우저의 `localStorage`에 자동으로 저장됩니다. 따라서 같은 브라우저와 기기에서는 페이지를 닫았다가 다시 열어도 내용이 유지됩니다.

서버 계정과 동기화되는 방식은 아니므로 다음 사항에 유의해 주세요.

- 다른 브라우저나 기기에서는 기존 할 일이 표시되지 않습니다.
- 브라우저의 사이트 데이터나 저장 공간을 삭제하면 할 일도 함께 사라질 수 있습니다.

## 로컬에서 실행하기

프로젝트 루트에서 정적 파일 서버를 실행한 뒤 브라우저로 접속합니다.

```bash
npx serve dist
```

서버가 안내하는 로컬 주소를 열면 서비스를 확인할 수 있습니다. 단순 확인만 필요한 경우 `dist/index.html`을 브라우저에서 직접 열 수도 있습니다.
